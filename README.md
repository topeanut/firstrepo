# Paper — 광고 없는 모바일 PDF 뷰어 & 에디터

설치 없이 브라우저에서 바로 쓰는 **PDF 뷰어 / 에디터**입니다.
광고·추적이 없고, 열어본 파일은 **기기 밖으로 전송되지 않습니다.** (모든 처리는 브라우저 안에서만)

## 주요 기능

- 📂 **열기** — 파일 선택 또는 드래그 앤 드롭
- 📜 **보기** — 연속 스크롤, 폭 맞춤 확대/축소, 페이지 이동, 썸네일 패널
- ✍️ **주석** — 펜 · 형광펜 · 지우개(색상/굵기 조절, 실행취소)
- 🔧 **편집** — 페이지 회전 · 삭제 · 순서 변경(길게 눌러 드래그)
- 💾 **저장** — 편집·주석을 반영해 새 PDF로 내보내기
- 🌙 **야간 모드** — 페이지 색 반전 / 라이트·다크 테마 자동
- 📱 **PWA** — 홈 화면에 설치, 첫 실행 후 오프라인 동작

## 사용법

정적 파일만으로 동작하므로 아무 정적 서버에서나 열면 됩니다.

```bash
# 예시
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 서비스워커(오프라인 설치)는 보안 컨텍스트에서만 동작합니다.
> `http://localhost` 또는 HTTPS로 접속하세요. `file://` 직접 열기에서는
> 뷰어·편집은 되지만 설치/오프라인은 비활성화됩니다.

## 기술 구성

순수 HTML/CSS/JS(빌드 단계 없음). 외부 의존성은 버전 고정 CDN 2개뿐입니다.

| 용도 | 라이브러리 |
|------|-----------|
| 렌더링 | [PDF.js](https://mozilla.github.io/pdf.js/) `3.11.174` |
| 편집·저장 | [pdf-lib](https://pdf-lib.js.org/) `1.17.1` |

```
index.html             # 화면 구조
manifest.webmanifest   # PWA 매니페스트
sw.js                  # 서비스워커(앱 셸 + 라이브러리 캐시)
assets/css/style.css   # 스타일(모바일 우선, 라이트/다크)
assets/js/app.js       # 뷰어·주석·페이지 편집·내보내기 로직
icons/                 # 앱 아이콘(SVG + PNG)
```

## 개인정보

- 서버 업로드 없음 · 분석/추적 스크립트 없음 · 계정 없음
- PDF 바이트와 주석은 **현재 탭의 메모리**에만 존재하며, 저장 시 사용자가 직접 내려받습니다.
- 테마/펜 설정만 브라우저 `localStorage`에 보관합니다.

## 알려진 제한 (v1)

- 텍스트 선택/검색, 스탬프형 텍스트 상자, 다른 PDF 병합은 아직 미지원(로드맵).
- 페이지 자체에 내재된 회전(`/Rotate ≠ 0`)이 있는 문서에서 주석을 함께 내보낼 때
  위치가 어긋날 수 있습니다(대부분의 문서는 `/Rotate = 0`).
